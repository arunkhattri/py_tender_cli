#+title: Tender cli application
* Objective
Build a CLI application for tender PDFs.

The application is concerned only with two parts of a tender:

1. Make List / Approved Makes
2. BOQ / SOQ (Schedule of Quantities)

Everything else in the tender is out of scope for now.
The eventual user workflow should be:

* Final Conceptual Model
** MAKE LIST
+ Reference/master list of permitted or recognized makes for material/product categories.
+ It does NOT indicate that the material is required in a particular project.
** SOQ / BOQ
+ Project-specific list of materials/items actually required by the tender.
+ A material appearing in the Make List does not imply that it is required in the project.
** SOQ MAKES
+ Makes explicitly specified against particular SOQ/BOQ items.
+ These are project-specific specifications and do not modify the Make List.
